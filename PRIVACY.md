# Privacy Policy

## Product

IRNK Veil: Gemini Watermark Cleaner is a Chrome extension by IRNK Codes.

## Local Processing

IRNK Veil processes supported Gemini image resources locally in the browser. Image cleanup is performed with browser APIs and does not require uploading user images to IRNK Codes servers.

## Data Collection

IRNK Veil does not include analytics SDKs by default and does not intentionally collect personal information.

## Local Storage

The extension may store the following data in Chrome local storage:

- extension enabled/disabled state,
- cleanup settings,
- debug preference,
- local cleanup statistics.

This data remains in the user's browser unless the user exports settings manually.

## Host Permissions

Host permissions are used to run the cleanup workflow on supported Gemini pages and related image resources.

## Network Requests

IRNK Veil does not send image content to IRNK Codes servers. Browser requests to Gemini and related image hosts are part of the user's normal browsing session and the extension's scoped cleanup workflow.

## Third-Party Affiliation

IRNK Veil is an independent tool by IRNK Codes and is not affiliated with, endorsed by, or sponsored by Google or Gemini.
