# Security Policy

## Supported Version

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting Security Issues

If you discover a security issue, please report it privately through:

```text
https://irnk.codes/support
```

Please include:

- affected version,
- browser version,
- reproduction steps,
- potential impact,
- relevant logs or screenshots.

## Security Principles

IRNK Veil is designed with these boundaries:

- image processing should remain local in the browser,
- extension permissions should stay scoped to supported pages/resources,
- sensitive image data should not be sent to IRNK Codes servers,
- failures should degrade safely without breaking the user's browsing session.

## Disclosure

Please do not publicly disclose unresolved security issues before IRNK Codes has had a reasonable opportunity to investigate and respond.
